About This Player

This page uses the native <video> and <audio> HTML5 elements, each with the controls attribute so the browser shows built-in play, pause, volume, and seek controls — no JavaScript required. Multiple <source> tags are used inside the video element so the browser can pick whichever format it supports.

  • ▶ Video source: MP4 and WEBM fallback formats
  • ▶ Audio source: MP3 format
  • ▶ Poster image shown before the video starts playing
